Drag from a dot on the right of a box to a model to connect it; click a line to select it, then remove it. Each request enters the Interceptor, which sends it to the Router (or straight to a pinned model). The Router's classifier scores it and picks a model; the Gateway (LiteLLM) then tries that model's fallbacks in order when it fails. Save writes the Router's choices to its config file, the Interceptor's to harness-settings.json, and the fallbacks to config.yaml. The Router and Interceptor use their changes on the next request; the Gateway needs a restart to use new fallbacks. Models come from config.yaml's model_list; other classifier settings are on the Dashboard.
