Assumptions behind the modeled numbers

Cheaper models often need more turns, retries or longer answers to get the same work done. Nothing here measures that, so it is a guess you can change. Each number is how many tokens a model needs for the same work, with Claude Sonnet 5.5 as 1. A model on 1.3 uses 30% more tokens than Sonnet would, and the comparison charges the baseline for fewer. Set everything to 1 to compare token for token.

Counts come from the usage each reply reports, read the same way the chat page and the dashboard read it (ui/tokens.js), so the three always agree. Values marked ~ are estimates (about 4 characters a token, from the request that was sent and the text that came back) for replies that had none, such as OpenAI streams without stream_options.include_usage. Costs are worked out for the model that answered from OpenRouter's own prices for OpenRouter models, else the Gateway's price list (LiteLLM's /v1/model/info), with cached input at the provider's cache price (a tenth of the input price for Claude when the list doesn't say). Free and local models cost nothing, and models with no listed price show ?. Totals are kept across restarts, in harness-usage.json or, on a hosted server, in the database. With logins on, this page counts only your own requests; admins see everyone on All users.
